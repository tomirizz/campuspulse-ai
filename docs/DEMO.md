# Демонстрация первой версии

Презентация рассчитана примерно на 5–6 минут. Для кейса GDG в исходнике не указан жёсткий тайминг; это рабочий вариант команды.

## Подготовка

Открыть приложение. Добавить два собственных задания или нажать «Добавить учебный пример» в подключениях. Не выдавать примеры за данные университета. Загрузить короткий PDF с текстом. Оставить открытой панель журнала.

## Сценарий выступления

1. **Проблема, 30 секунд.** У студента задания, материалы и GitHub находятся в разных местах. CampusPulse помогает понять, что делать дальше и хватает ли времени.
2. **Продукт, 45 секунд.** Добавить задание с дедлайном и оценкой. Показать неделю, изменить дневную нагрузку. Показать предупреждение, если задача не помещается до срока.
3. **Агент и MCP, 90 секунд.** При подключённом Gemini: «Проверь GitHub issues googleapis/python-genai и предложи следующий учебный шаг». Раскрыть реальный `github_issues` в журнале: аргументы, источник, fetched_at. Показать цикл tool call → observation → ответ. При tools mode прямо сказать: «Сейчас демонстрируем инструменты без ИИ; живой Gemini ожидает подключения».
4. **Материалы, 45 секунд.** Спросить о загруженной лекции. В режиме Gemini показать `list_materials` → `read_material`, ответ с именем и страницей. Без Gemini показать только извлечение текста и честно назвать границу.
5. **Архитектура и облако, 60 секунд.** Browser → Cloud Run → Agent Engine → Gemini/MCP. Показать `ReasoningEngine.create`, а после реального запуска — фактический resource name и успешную проверку API. До запуска не заменять их макетом облачной консоли.
6. **Ограничения и развитие, 45 секунд.** Человеческое подтверждение изменений, нехватка времени, ошибки внешних сервисов. Далее: подключить облако, добавить аккаунты, интеграцию с LMS и обратную связь студентов.

## Проверяемые сценарии

| Сценарий | Вход | Ожидаемый результат |
|---|---|---|
| Пустое пространство | «План недели» | Просьба добавить задания, без выдуманных курсов |
| Обычная неделя | 2 задания, 180 минут в день | Блоки в доступное время, до дедлайнов |
| Перегрузка | 10 часов работы до завтра, доступно 1 ч | Честное число незапланированных минут |
| Пары в календаре | Занятой интервал 16:00–18:00 | Ни одного учебного блока внутри него |
| Просроченное задание | Вчерашний deadline | Риск «Дедлайн прошёл», без планирования в прошлом |
| GitHub | Публичный owner/repo | Свежие issues и URL через MCP |
| Ошибка GitHub | Несуществующий repo / rate limit | Явная ошибка, без выдуманного результата |
| Материал | PDF с текстом | Страницы прочитаны; Gemini цитирует источник |
| Скан | PDF без текста | Сообщение о необходимости OCR |
| Предложение задачи | Запрос с курсом и дедлайном | Форма проверки; до нажатия «Сохранить» данных нет |
| Изоляция | Две cookie-сессии | Каждая видит только своё пространство |
| Нет Gemini | Режим gemini без credentials | Ошибка подключения; нет скрытого перехода к шаблонному ответу |

## Следующие дни

1. Подключить биллинг и ADC, проверить Gemini, развернуть Agent Engine, сохранить реальную трассу. Это закрытие оставшегося обязательного пункта, а не необязательное улучшение.
2. Проверить Cloud Run/Firestore; подготовить доступ для судей. Протестировать 3–5 сценариев реальными студентами без заявления о результатах до исследования.
3. По обратной связи улучшить язык, добавить авторизацию и затем выбрать одну интеграцию: LMS или Google Calendar. Не расширять число интеграций до стабильной облачной демонстрации.
