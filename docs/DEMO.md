# Демонстрация CampusPulse AI

Основной сценарий: силлабус → оценки → достижимая цель → приоритет → свободное время. Примеры ниже демонстрационные; их нельзя выдавать за оценки реального студента или успешное облачное развёртывание.

## Основной сценарий: около пяти минут

1. Откройте «Мои предметы → Загрузить силлабус → Пример силлабуса HPC». Это точно переписанный предоставленный пример, а не результат безошибочного OCR. Проверьте High Performance Computing (HPC), 5 кредитов, итоговые веса 12/18/6/6/18/40%. Объясните: 40% задания внутри аттестации × 30% аттестации = 12% всего курса. Сохраните после проверки.
2. Введите демонстрационные 75 за Assignment 1 и 80 за Mid Term. Текущий средний — 78% по проверенным 30% курса, набрано 23,4 итоговых балла, максимум — 93,4. Цель 95 недостижима; рабочая ступень становится 90.
3. Для цели 90 на оставшихся 70% нужен средний 95,142857…%. Равномерный план с округлением — по 96/100 на четырёх оставшихся работах; итог 90,6. Это один совместно выполнимый вариант, а не единственный минимум каждого экзамена. Условные минимумы предполагают максимум на остальных и не составляют общий план.
4. Покажите ступени 95/90/85/80/75/70 и GPA. Шкала редактируется; 70 → GPA 2,0 и 65 → 1,67 подтверждены пользователем, другие ступени предварительные. Текущий GPA взвешен по кредитам и предварителен; целевой GPA — сценарий. Scholarship saver не подтверждает право на стипендию.
5. Добавьте второй предмет с проверенными весами. Задайте сложность либо оставьте предварительную оценку по названию. Ухудшите оценку первого предмета и покажите пересортировку по риску, кредитам, сложности и срокам. Снижение рабочей цели не маскирует ухудшение предмета.
6. Откройте план подготовки. По умолчанию окно 16:00–22:00 и 180 минут работы в день. Блоки обычно 25–50 минут; реальная короткая задача, тесное окно или малый лимит могут дать 15–24 минуты с пояснением. Есть перерывы; завершённым предметам время не назначается. Нехватка времени показана отдельно. План не гарантирует будущую оценку.
7. В «Моё расписание» загрузите предоставленное расписание экзаменов. Проверьте год и даты. Май–июнь 2026 прошли относительно октября 2026: система предупреждает и не переносит их в будущее. Экзамены не превращаются в еженедельные пары. Для наглядного ограничения текущего плана добавьте будущий занятый интервал и убедитесь, что блок подготовки туда не попал.

## Проверка реального импорта

Загрузите свой PDF с выделяемым текстом или TXT/MD. Для PNG/JPG используется доступное локальное OCR. Покажите исходный распознанный текст и предупреждения до сохранения. Обрезанный скриншот может потерять коэффициенты 0,3/0,4, перепутать 1/I или сместить число к соседней строке. Правильный результат здесь — неполная схема с предупреждением, а не выдуманные веса. Вставка точного текста и явно обозначенная кнопка примера проверяют формулу отдельно от качества картинки.

Импорт сам по себе не сохраняет предмет. Полная схема должна давать 100%. Пустая оценка неизвестна, 0 — реальный нулевой результат. Допуск и обязательный минимум финального экзамена отдельно этой моделью не доказываются.

## Остальные части продукта

1. «Материалы»: загрузите настоящий конспект/PDF, найдите термин; покажите цитату, страницу и строку. Различающиеся числа требуют сверки контекста, а не автоматически означают ошибку.
2. «Моя неделя → Что, если…»: уменьшите доступные минуты; сравните блоки и риски. Основные настройки от предварительного сценария не меняются.
3. «Практика → Нужная оценка»: старый калькулятор одной неизвестной. При 60% курса с результатом 80/100, финале 40% и цели 85 нужен финал 92,50/100. Цель 95 недостижима, максимум 88. Новый план предмета с несколькими неизвестными — отдельный расчёт.
4. «Учебные квесты»: загрузите определения, проверьте эталоны, начните тренировку. Покажите источник и уникальную награду; повтор факта не добавляет XP снова. XP отражает активность по правилам приложения, не знания в целом.
5. «Проверка кода»: ошибка Python показывает строку/столбец. Успех подтверждает только синтаксис, не правильность алгоритма или пройденные тесты.

## Конспект по нескольким источникам и скачивание

В «Материалах» загрузите два настоящих файла PDF/TXT/MD с лекциями. В создании конспекта выберите оба источника, задайте фокус и стиль: кратко, к экзамену или карточки. Покажите разделы, определения, вопросы с ответами и точные ссылки на файлы/страницы. Откройте сохранённый конспект повторно и скачайте PDF, Markdown, TXT или HTML. В PDF проверьте кириллицу, номера страниц и список цитат.

Без Gemini это честно подписанная экстрактивная выжимка: текст выбирается из источников, вопросы проверяют восстановление фактов. При подключённом Gemini возможен более связный педагогический пересказ с теми же цитатами. Только успешный проверенный ответ получает метку Gemini. При недоступности модели или некорректных ссылках остаётся локальная версия с предупреждением. Валидная ссылка не гарантирует, что модель правильно истолковала источник, — покажите возможность сверки.

## Чат, MCP и Google

В режиме tools запросы «Как мои оценки и GPA?» и «Распредели время по предметам» вызывают те же детерминированные расчёты. Журнал показывает реальные локальные вызовы, включая MCP current_time. Выбор по правилам не называется автономным выбором Gemini.

После настройки Gemini покажите многошаговый выбор current_time → academic_overview → academic_plan либо list_materials → syllabus_weights. Затем после развёртывания Agent Engine повторите запрос через удалённый API и сохраните evidence. До успешных живых ответов эти пункты открыты.

В Calendar запрос без даты и времени вызывает уточнение. Без OAuth событие не создано — ответ должен прямо это сказать. С настроенным подключением покажите проверку занятости, реальную запись и настоящую ссылку; повтор не создаёт дубликат, пересечение требует явного подтверждения. Для личного календаря используйте согласованные тестовые события.

Перед сдачей отдельно подтвердите live Gemini, доступный Agent Engine API, Calendar OAuth/настоящий ответ при заявлении этой интеграции и актуальную презентацию. Код, локальные тесты и прежняя презентация этих результатов не заменяют.
