# Проверка продукта v0.2 (не презентация)

1. Запустить локальный ИИ через файл запуска. Убедиться, что в интерфейсе виден режим без ключа.
2. Добавить своё задание и открыть «Почему?» у награды: исходная оценка минут и формула.
3. Завершить → проверить XP, карту пути, достижение и журнал начислений. Вернуть в работу → XP убирается. Повторно завершить → тот же XP.
4. Спросить об опыте в чате. Открыть источник, затем журнал `study_progress`.
5. Построить неделю. Проверить формулу суммы времени и причину блока/нехватки. Экспортировать ICS.
6. Загрузить текстовый учебный материал. Спросить о факте из него. Сверить цитату, страницу и строку.
7. Попросить проверить `googleapis/python-genai`. Показать реальный MCP и URL issues.
8. Показать ограничения: нет ключа у локального ИИ, но первая загрузка нужна; Gemini/Agent Engine ещё не развёрнуты. Баллы — саморегистрация работы, не оценка знаний.

Учебные примеры должны быть явно помечены `[Пример]`. Не представлять синтетические данные как реальные задания университета. Слайды не обновляются до финального продукта.
