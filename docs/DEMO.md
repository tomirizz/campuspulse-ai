# Проверка продукта · v0.3

Это сценарий демонстрации, не презентация. Не показывать тестовые данные как реальные учебные результаты.

1. Загрузить свой текстовый силлабус. Открыть «Разобрать силлабус», показать точную строку срока. У задания без времени поле должно остаться пустым. Подтвердить одно задание, самостоятельно задать курс/оценку минут, показать сохранённый источник.
2. В «Моей неделе» построить план. Раскрыть «Что, если…», уменьшить доступные минуты/отложить начало. Сравнить блоки и риски, показать формулу разницы. Основные настройки не изменились.
3. Загрузить два конспекта, найти один термин. Показать две точные цитаты, страницы и строки. Разные числа помечаются как возможное расхождение, не автоматически признанная ошибка.
4. «Практика → Нужная оценка»: в учебном примере известный компонент весом 60% имеет 80 из 100; финал весит 40%, цель 85. Результат — 92,50 из 100. Показать подстановку; изменить цель на 95 — недостижима (максимум 88). Не называть эти числа оценками реального пользователя.
5. «Учебные квесты»: конспект со строками «Градиент: вектор частных производных» и «Эпоха: один проход по выборке». Проверить эталоны, начать, ответить, показать источник и XP. Повторить тот же факт — общий XP не растёт второй раз. Неправильный ответ показывает эталон и цитату.
6. «Проверка кода»: Python-фрагмент с синтаксической ошибкой показывает фактическую строку/столбец. Валидный фрагмент даёт только результат синтаксической проверки, не заявление о прохождении тестов.
7. В чате: «Запланируй хакатон» → уточнение дня/времени → ответ с будущей датой и временем. Без Google — незавершённый запрос и честное сообщение, что события нет. С настроенным OAuth — проверка занятости, добавление и настоящая ссылка. Повтор не создаёт второй экземпляр. Пересечение требует отдельного разрешения «всё равно».
8. После подключения Gemini: показать самостоятельный выбор инструментов (список материалов → поиск/чтение → выбор подтверждённых фактов). Затем повторить через реальный Agent Engine endpoint и сохранить журнал. Эта часть ожидает подключения облака.

## Чего не заявлять

- Контрактные тесты API не равны доступу к живому Google Calendar или Agent Engine.
- Режим tools и календарный state machine не являются живым Gemini.
- XP не измеряет знания; квесты проверяют воспроизведение подтверждённого текста.
- Лексический поиск не гарантирует извлечение всего смысла документа; синтаксический анализ не доказывает правильность программы.
- Презентация будет сделана после готовности финального продукта.
