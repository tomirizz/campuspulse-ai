# Требования и критерии GDG Astana — v0.2

Источник: «FINAL Задачи_хакатона.docx.pdf», кейс 2, страницы 3–4. Не смешиваем с кейсом Smart City. Перечень примеров студенческих сценариев не является требованием реализовать все перечисленные интеграции.

| Критерий из задания | Что внедрено | Что ещё нужно для полной проверки |
|---|---|---|
| MCP & Tools Usage | Настоящий MCP SDK stdio: текущее время, публичные GitHub issues. Custom functions: задания, план, прогресс, список материалов, чтение страниц. JSON Schema и allowlist. | Реальные вызовы проверяются локально; необходимо повторить в Agent Engine |
| GCP Agent Engine Deployment | `ReasoningEngine.create`, проверка удалённого API, приватный Cloud Run, адаптер Firestore | **Не закрыт:** облако отложено владельцем, биллинг не подключён |
| AI Logic & Autonomy | Gemini: ограниченный автономный цикл; локально: обязательные источники метрик по правилам и выбор материала/фактов моделью; отдельный строгий этап выбора существующих фактов; Gemini + локальный Qwen без ключа | Локальные тесты и живые проверки фиксируются отдельно. **Живой Gemini пока не проверен** |
| UX & Visualization | Адаптивный интерфейс, миссии/опыт/уровни/карта/достижения, фокус, «Почему?», история начислений, фактический журнал вызовов с аргументами, результатами и длительностью | Финальная проверка браузера и устройств; журнал показывает наблюдаемые действия, не скрытые размышления |
| Architecture & Presentation | Разделены правила, планировщик, данные, агент, MCP и evidence-renderer. README, архитектура, tools, deployment, тесты | **Презентация отложена по просьбе владельца.** Файл v0.1 сохранён как старый черновик и не описывает v0.2 |

Обязательный Gemini core остаётся в `campuspulse/agent.py`. Для использования сайта локально ключ не нужен: `local_agent.py` использует Ollama/Qwen. Для публичного Gemini-сервиса ключ пользователю также не должен требоваться: облачные credentials принадлежат серверу, однако владельцу нужны GCP-проект, биллинг и развёртывание. Это не обход требований Google и не бесплатный облачный Gemini.

## Новые правила владельца

| Правило | Реализация |
|---|---|
| Вычисления по формуле, не из ответа ИИ | `progress.py`, `planner.py`, серверные метрики; детерминированные правила и regression tests |
| ИИ объясняет, не придумывает числа/код | Финальный ответ модели содержит только ID фактов и код объяснения. Итоговые факты/цитаты вставляет сервер; инструмента выполнения кода нет |
| Запуск ассистента без API-ключа | Локальный Qwen через Ollama, launcher и проверка readiness; без регистрации |
| У каждого ответа «почему» | Формула, входы, источник и результат в показателях, наградах, плане, цитатах, GitHub и новых сообщениях; ошибки с причиной |
| Интерактивная геймификация | Транзакционное завершение задания → XP → уровень → этапы/достижения; повторное начисление исключено; таймер без XP |
| Презентация в конце | Новые слайды в этой итерации не создаются |

Нельзя заявлять «всё ТЗ полностью закрыто», пока нет успешного живого Gemini, Agent Engine и удалённой демонстрации. Тест локальной модели не является доказательством этих пунктов.
