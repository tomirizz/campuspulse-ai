# Соответствие ТЗ GDG Astana · v0.3

Источник: «FINAL Задачи_хакатона.docx.pdf», кейс 2, страницы 3–4. Примеры GitHub/Maps/локальных файлов в задании — возможные сценарии, не обязательный перечень интеграций. По последнему требованию владельца ИИ и внешние сервисы переведены на Google. Python, FastAPI, MCP SDK и собственные функции — код реализации, не альтернативный ИИ-провайдер.

| Критерий | Реализация | Проверка / открытый пункт |
|---|---|---|
| MCP & Tools Usage | Настоящий MCP stdio `current_time`; Gemini Function Calling: план, материалы, силлабус, поиск, оценки, квесты, диагностика, события. Реальный адаптер Google Calendar events.list/events.insert. | MCP и функции выполнены локально; Calendar API — контрактные тесты. **Живое разрешение Calendar ещё не настроено.** |
| GCP Agent Engine Deployment | `ReasoningEngine.create/update`, удалённый OAuth query, Cloud Run, Firestore, скрипты настройки и проверки. | **Не закрыт:** биллинг и развёртывание отложены владельцем. |
| AI Logic & Autonomy | Google Gen AI SDK; Gemini сам выбирает инструменты, видит наблюдения, повторяет вызовы; предел 8 раундов/12 вызовов; оригинальные function-call IDs/thought signatures сохраняются. Ответы из проверенных фактов. | Многошаговые контрактные тесты SDK и настоящего MCP. **Live Gemini ещё не проверен.** Детерминированный резервный режим и календарные правила не выдаются за автономный ИИ. |
| UX & Visualization | Компактный чат; неделя/Google Calendar; материалы/силлабус/поиск; одна «Практика» с 3 инструментами. Источники, ошибки, уточнения, карта пути, XP и реальный журнал действий. | Браузерные проверки и адаптивная вёрстка; журнал не раскрывает скрытые рассуждения. |
| Architecture & Presentation | Разделены правила, данные, агент, MCP, Calendar/OAuth и UI; документация, тесты, воспроизводимый архив. | **Презентация отложена владельцем.** Старый файл v0.1 не описывает текущий продукт. |

## Уточнения владельца

| Требование | Как обеспечено |
|---|---|
| Только Google для ИИ и внешних сервисов | Vertex AI Gemini, Google Calendar, GCP. Qwen/Ollama и GitHub tool удалены из активного проекта. |
| Без API-ключа для пользователя | ADC/служебный аккаунт сервера для Gemini, OAuth-кнопка для личного Calendar. Владельцу всё равно требуется настроенный проект и OAuth-клиент. |
| Все вычисления по готовому правилу | Планировщик, Decimal-калькулятор оценок, XP, оценка квеста и интервалы календаря считаются кодом. Модель не задаёт входы оценок/сценария произвольно. |
| У каждого результата «почему» | Общий proof: формула, входы, результат, источник и ограничения. Цитаты сверяются с точным текстом; ошибки имеют причину. |
| Добавление событий обычным сообщением | Прямой пользовательский запрос → разбор → уточнение → проверка занятости → events.insert → фактический ответ. Нет связи с Google — остаётся незавершённый запрос. |
| Без усложнения интерфейса | Основные действия в существующих разделах; квесты, оценка и код собраны в одной вкладке. |

Полное выполнение ТЗ нельзя объявлять до живой проверки Gemini, доступного Agent Engine API и финальной презентации. Успешные тесты с подменённой границей Google API не являются облачным развёртыванием.
