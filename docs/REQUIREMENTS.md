# Соответствие кейсу CampusPulse AI

Источник: «FINAL Задачи_хакатона.docx.pdf», кейс CampusPulse AI. Обязательны агент с Gemini и инструментами/MCP, Vertex AI Agent Engine / Reasoning Engine с доступным API, интерфейс с наблюдаемыми вызовами, демонстрация и презентация. GitHub, карты и конкретный набор студенческих инструментов приведены как возможные сценарии.

| Критерий | Реализованный код и локальная демонстрация | Что ещё подтвердить |
|---|---|---|
| Ядро агента и инструменты | Google Gen AI SDK, ограниченный цикл Function Calling, настоящий MCP stdio current_time; live Gemini 3.5 Flash выполнил current_time → academic_overview → academic_plan с проверенным ответом | Локальный Developer API не доказывает доступ к Vertex AI или Agent Engine; режим tools — не автономный ИИ |
| Работа с реальными данными | PDF/TXT/MD и изображения с доступным локальным OCR, цитаты, подтверждённые веса, введённые оценки, датированное расписание, адаптер Calendar API | Качество OCR зависит от изображения/движка; плохие таблицы требуют проверки. Calendar требует OAuth и реального API-ответа |
| GCP Agent Engine | Скрипты ReasoningEngine.create/update, удалённого query и verify_cloud | Не закрыто до реального развёртывания и доступного API; нужны проект, биллинг, IAM/ADC и успешная удалённая проверка |
| Веб-интерфейс | Предметы, цели, GPA, план, чат, материалы, календарь, практика, источники, журнал | Локальный UI не равен размещённому Cloud Run-сервису; облачный URL проверяется отдельно |
| Демо и презентация | Сценарий [DEMO.md](DEMO.md), архитектура, формулы, тесты | Финальная презентация должна отражать текущую реализацию; прежний файл не обновляется автоматически |

## Запрошенный учебный контур

| Пожелание | Реализация и граница |
|---|---|
| Проценты из силлабуса | Плоские проценты либо вложенная формула аттестаций. Пример HPC: 12/18/6/6/18/40%. Подытог Assignments не суммируется повторно с дочерними работами |
| Нужные баллы нескольких работ | Равномерный нормированный план, округление вверх, проверка итога. Условный минимум отдельной работы предполагает максимум остальных и не является общим планом |
| Цель 95 с переходом к 90/85/80/75/70 | После оценки проверяется максимум и выбирается высшая достижимая ступень в пользовательском диапазоне |
| GPA | Личная редактируемая шкала; 70 → 2,0 и 65 → 1,67 подтверждены пользователем. Прочие ступени предварительные; текущий GPA взвешен по кредитам и предварителен |
| Сложность и важность | Эвристика названия либо ручная сложность 1–5; риск, кредиты и сроки дают объяснимый приоритет. Это не объективное измерение сложности |
| Ухудшившийся предмет поднимается | Дефицит считается относительно исходной желаемой цели; понижение рабочей цели не скрывает ухудшение |
| Свободное время без множества настроек | По умолчанию 16:00–22:00, 180 минут. Из окна исключаются пользовательские/импортированные интервалы и доступная занятость Calendar. Сон и дорога не угадываются |
| Реалистичные блоки | Обычно 25–50 минут, минимум 15, с перерывами; жёсткие лимит дня, занятость и сроки. Оценка времени редактируется и не гарантирует балл |
| Расписание экзаменов | Конкретные даты и год, включая объединённую ячейку даты. Прошлое не переносится молча; экзамены не становятся еженедельными парами |
| Срок экзамена в плане предмета | Нормализованное название или уникальный акроним и однозначный тип работы. Неизвестное/неоднозначное соответствие не угадывается |

Формулы, пример и ограничения: [ACADEMIC.md](ACADEMIC.md). Scholarship saver — мотивационная подпись, не подтверждение правил стипендии. Допуск, обязательный минимум финала, штрафы и специальные правила кафедры без подтверждённых данных автоматически не моделируются.

## Проверка и честный статус

Арифметика оценок, импорт, инварианты плана, API и инструменты проверяются автоматическими тестами; браузер отдельно проверяет пользовательский поток. Подмена Google API в тесте доказывает контракт, а не реальное подключение Gemini, OAuth или GCP.

verification*.json прежних версий — исторические отчёты. Их даты, число тестов и скриншоты не подтверждают новые функции автоматически. Актуальный прогон и live-результат требуют собственных даты, области проверки и evidence.

Полное выполнение ТЗ нельзя объявлять до live Gemini, Agent Engine с доступным API и актуальной презентации. [DEPLOYMENT.md](DEPLOYMENT.md) описывает настройку; наличие инструкции не означает, что она выполнена.
