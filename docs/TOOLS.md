# Инструменты и доказательства

| Инструмент | Транспорт | Источник / формула |
|---|---|---|
| `current_time(timezone_name)` | MCP stdio | Часы сервера + IANA timezone |
| `github_issues(repository)` | MCP stdio | Живой GitHub API, только public repo, до 30 последних записей, PR исключены |
| `list_tasks()` | Function Calling | Задания текущей сессии |
| `plan_week()` | Function Calling | `planner.py`: ближайшие дедлайны первыми, сетка 15 мин, блок до 60 мин, исключены busy и соблюдён дневной лимит |
| `study_progress()` | Function Calling | `progress.py`: версия правил, XP/уровень/серия + все proof |
| `list_materials()` | Function Calling | Метаданные загруженных файлов текущей сессии |
| `read_material(material_id,page)` | Function Calling | До трёх страниц извлечённого текста; итоговая цитата проверяется сервером |

ToolHub устанавливает реальный MCP-сеанс и выполняет discovery через `list_tools`. Только два разрешённых имени подключаются из MCP; аргументы проходят JSON Schema. Произвольные URL, пути файлов и shell-команды недоступны.

Журнал отражает фактически выполненные вызовы, ошибки и измеренное время (разность монотонных часов), а не внутреннюю цепочку размышлений модели. Источники в ответах — отдельные карточки с «Почему?».

Задания сохраняются только через форму или явную отметку пользователя. Модель не может назначать себе баллы и не имеет инструмента записи заданий.
