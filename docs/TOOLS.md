# Инструменты · v0.3

| Инструмент | Путь | Источник и правило |
|---|---|---|
| `current_time(timezone_name)` | Настоящий MCP stdio | Часы сервера + IANA timezone |
| `list_tasks()` | Gemini Function Calling | Сохранённые задания сессии |
| `study_progress()` | Function Calling | Формулы наград, уникальные квесты, уровень, серия |
| `plan_week()` | Function Calling | Дедлайны, оценки длительности, доступность; Google busy-интервалы из актуального снимка |
| `list_materials()` / `read_material(id,page)` | Function Calling | До 3 страниц реального файла; никаких произвольных путей |
| `search_materials(query)` | Function Calling / форма | Все файлы сессии, фиксированное лексическое ранжирование, точные фрагменты |
| `read_syllabus(material_id)` | Function Calling / форма | Строки заданий и правил оценивания; предложения требуют проверки |
| `compare_plan()` | Function Calling | Входы из явных чисел пользовательского запроса либо подтверждённой формы сценария; модель не назначает доступность |
| `grade_target()` | Function Calling | Только сохранённая, подтверждённая пользователем система оценивания; Decimal |
| `learning_quests(material_id)` | Function Calling | Кандидаты вопросов по цитатам; запуск и подтверждение эталона — форма |
| `diagnose_code()` | Function Calling | Код только из прямого блока пользователя либо результат формы; compile без exec / JSON parser |
| `calendar_events()` | Function Calling | Снимок Google Calendar с временем получения и диапазоном |
| `parse_calendar_request` | Серверный диалог | Явная команда пользователя, фиксированный разбор даты/времени |
| `google_calendar_list` / `google_calendar_insert` | Google Calendar API, отдельный путь записи | OAuth основного календаря; не инструменты произвольной записи для модели |

Каждый вызов возвращает данные или явную ошибку. Журнал содержит аргументы, результат, длительность и реальный способ выбора (Gemini либо правила команды). Секретов в нём нет. Gemini ограничен 8 раундами/12 вызовами. Неизвестные инструменты и аргументы вне схемы отклоняются.

## Основные формулы

- Вклад оценки = вес% × набранный балл / максимум компонента.
- Нужный балл = max(0, (цель − сумма известных вкладов) × максимум неизвестного компонента / его вес%). Округление вверх до 0,01; при превышении максимума цель недостижима.
- Поиск: score = число совпавших префиксов длиной до 6 символов после исключения стоп-слов. Это не confidence.
- Пересечение событий: startA < endB и endA > startB.
- Результат квеста = floor(правильных / всех вопросов × 100%).
- Квест XP = 10 за первый правильно восстановленный уникальный факт; миссия XP = 20 + min(40, 5 × ceil(оценка минут / 30)).
- Сравнение плана: Δ = scheduled_minutes нового − scheduled_minutes исходного при одном now.
