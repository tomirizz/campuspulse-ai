# Инструменты CampusPulse AI

current_time обнаруживается и вызывается через настоящий локальный MCP stdio-сервер. Остальные инструменты — собственные функции с JSON Schema для Gemini Function Calling. Формы используют те же расчётные модули. Наличие локальных функций не подтверждает живую работу Gemini или облачное развёртывание.

| Инструмент | Способ вызова | Данные и правило |
|---|---|---|
| current_time(timezone_name) | MCP stdio | Часы сервера и IANA timezone |
| academic_overview() | Function Calling | Подтверждённые предметы, веса и оценки → текущий результат, достижимые цели, GPA, приоритеты |
| academic_plan() | Function Calling | Предметы, задачи, доступность, импортированное расписание и доступная занятость Calendar → план подготовки |
| syllabus_weights(material_id) | Function Calling | Название, кредиты и вложенные веса реального силлабуса; предложение для проверки, без автоматического сохранения |
| list_tasks() | Function Calling | Сохранённые задания пространства |
| study_progress() | Function Calling | XP, уровень, серия, уникальные награды и формулы |
| plan_week() | Function Calling | Обычный план заданий по срокам и доступности; отдельный от распределения времени по предметам |
| list_materials() / read_material(id,page) | Function Calling | Файлы пространства и до трёх страниц материала; произвольные пути недоступны |
| search_materials(query) | Function Calling / форма | Лексический поиск, точные фрагменты, страницы и строки |
| read_syllabus(material_id) | Function Calling / форма | Предложения заданий и цитаты правил; недостающие поля заполняет пользователь |
| compare_plan() | Function Calling | Явный сценарий доступности без изменения сохранённых настроек |
| grade_target() | Function Calling | Старый калькулятор одной неизвестной оценки из подтверждённой формы «Практики» |
| learning_quests(material_id) | Function Calling | Предложения вопросов по цитатам; эталоны проверяются в форме |
| diagnose_code() | Function Calling | Синтаксис Python или JSON; код пользователя не исполняется |
| calendar_events() | Function Calling | Снимок Google Calendar с датой получения и диапазоном покрытия |
| parse_calendar_request | Серверный диалог | Прямая команда пользователя, дата и время, уточнения |
| google_calendar_list / google_calendar_insert | Google Calendar API | OAuth основного собственного календаря; запись после прямой команды |

Академический импорт PDF/TXT/MD/PNG/JPG и датированного расписания доступен в формах и /api/academic/import, /api/academic/import/file. Это не дополнительные MCP-инструменты. Предмет, оценки, настройки и расписание сохраняются явными действиями пользователя.

## Конспекты по материалам

POST /api/notebooks принимает 1–10 материалов текущего пространства, фокус и стиль: summary, exam или flashcards. Локальный notebooks.py отбирает точные фрагменты, определения и вопросы для самопроверки; каждый абзац и ответ имеют ссылки на файл, страницу и цитату. Этот режим явно обозначен как экстрактивный, без заявления о работе Gemini.

Если серверный Gemini настроен и выбран не режим tools, notebook_ai.py делает один ограниченный запрос к Google Gemini. Схема ограничивает результат шестью разделами, двенадцатью абзацами, двенадцатью терминами и десятью вопросами. Все ссылки должны указывать на выбранные источники; новые числа, отсутствующие в связанных цитатах, отклоняются. Исходные цитаты модель не изменяет. Наличие ссылки не доказывает смысловую правильность пересказа: его всё равно нужно сверять.

Только успешно проверенный ответ получает mode=gemini, имя модели и журнал вызова. При ошибке/таймауте сохраняется экстрактивная выжимка с явным ai_warning; секреты и полный ответ ошибки провайдера не отображаются. Не настроенный Gemini не требуется для локального конспекта.

GET /api/notebooks показывает сохранённые конспекты, GET/DELETE /api/notebooks/{id} открывает/удаляет собственный конспект. GET /api/notebooks/{id}/export?format=pdf|md|txt|html скачивает документ с цитатами и ответами. PDF использует ReportLab и шрифт с кириллицей; HTML экранирует пользовательский текст. API разделяет данные по сессиям. Это отдельный пользовательский поток, не MCP-инструмент и не произвольная запись от модели.

Журнал содержит аргументы, результат, длительность и способ выбора: Gemini либо правила режима tools. Он показывает выполненные действия и наблюдения, а не скрытые рассуждения модели. Gemini ограничен восемью раундами и двенадцатью вызовами. Неизвестные инструменты и аргументы вне схемы отклоняются.

## Проверяемые правила

- Вклад оценки = вес × балл / максимум работы.
- Текущий средний = набранные итоговые баллы / проверенный вес × 100. Это не гарантированный итог курса.
- Максимум = набранные итоговые баллы + оставшийся вес.
- Равномерный план нескольких оставшихся работ: одинаковый нормированный процент max(0, цель − набрано) / оставшийся вес × 100, затем округление вверх до допустимого шага каждой работы. Общий итог проверяется после округления.
- Условный минимум одной работы предполагает 100% на всех остальных неизвестных работах. Такие минимумы нельзя складывать в общий план.
- Глобальный вес = вес аттестации × внутренний вес работы / 100. В предоставленном примере HPC: 12 + 18 + 6 + 6 + 18 + 40 = 100%.
- Академический приоритет: риск + близость дедлайна + 1,5 × min(кредиты, 10) + 2 × сложность + дефицит относительно исходной желаемой цели. Завершённый предмет получает ноль.
- Распределение времени учитывает кредиты × сложность × множитель риска, близость срока и уже выделенные минуты. Доступность, лимит дня и дедлайн — жёсткие ограничения.
- GPA = Σ(GPA предмета × кредиты) / Σ(кредиты учтённых предметов). Текущий GPA предварительный; предметы без оценок исключаются. 70 → 2,0 и 65 → 1,67 подтверждены пользователем; другие ступени личной шкалы предварительные и редактируемые.
- Поиск: число совпавших префиксов длиной до шести символов после исключения стоп-слов; это не вероятность правильности.
- Пересечение: startA < endB и endA > startB.
- Квест XP: 10 за первый правильно восстановленный уникальный факт. XP миссии: 20 + min(40, 5 × ceil(оценка минут / 30)).
