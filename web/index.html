Квесты строятся из строк «термин: определение» в твоих материалах. Сначала проверяем эталоны, затем тренируемся.

Сколько нужно набрать?

Для курса с взвешенной суммой оценок. Введи реальные веса из силлабуса и оставь один компонент неизвестным. Сумма весов — 100%.

Пойми ошибку в коде

Точный результат синтаксического анализатора, строка и причина. Проверяется синтаксис Python или JSON; выполнение программы не запускается.

ПРОЗРАЧНО ПО УМОЛЧАНИЮ

Подключения и данные.

Что работает сейчас и откуда берётся информация.

Google Calendar

Войди в Google и разреши доступ к событиям своего основного календаря. Личный API-ключ не нужен. События добавляются только по твоей явной просьбе.

Настройка подключения выполняется владельцем приложения один раз. Пока Google не подключён, незавершённый запрос сохраняется как черновик.

Твоё пространство

Задания, текст материалов и последние сообщения хранятся для этого браузера. Локальная версия использует SQLite; облачная конфигурация — Firestore. Без cookie восстановление пространства в первой версии недоступно.

Учебный пример создаёт три явно помеченных задания. Он не используется как источник реальных данных.
